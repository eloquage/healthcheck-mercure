# Changelog

All notable changes to `healthcheck-mercure` will be documented in this file.

## v0.1.7 - 2026-11-03

- Align Composer author and keyword metadata with Eloquage.

## v0.1.6 - 2026-11-03

Release the package with Composer identity under the eloquage vendor namespace. This release contains the package metadata and documentation rename; runtime behavior is unchanged.

## 0.1.5 - 2026-10-23

- Support Laravel 12 and 13 on PHP 8.3+.
- Open and close the Mercure subscription stream after receiving headers.
- Respect package topic, timeout, token, and required settings.
- Add package banner and concise setup and usage examples.
